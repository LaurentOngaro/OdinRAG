# GitIngest snapshots

> Snapshots generated by [`gitingest`](https://gitingest.com/) over the **local** clones under `D:\Sources\Odin\`.
> Each `*.txt` is the canonical "everything-in-the-repo" digest for one source.
> Regenerate any file in 1-2 minutes via the CLI (see [How to regenerate](#how-to-regenerate)).

## Purpose

The Perplexity **Space** "Odin Assistant Projet jeu" needs _stable, query-ready_ dumps of Odin-related repositories. Pasting a 50-file project tree into Perplexity one file at a time is brittle; uploading one `gitingest`-style text file gives the assistant the full project as auto-injected context.

These snapshots are **not** the primary source of truth for the curated KB (that is `odin-knowledge-base/docs/`). They are a convenience layer for LLM contexts that cannot reach the live repos via MCP.

## How to regenerate

All snapshots are produced by the durable script `_Helpers/scripts/scrapers/build_gitingest.py` (or by hand, see below).

### Via the script (recommended)

```bash
# regenerate everything that is out-of-date
python _Helpers/scripts/scrapers/build_gitingest.py

# regenerate a single source
python _Helpers/scripts/scrapers/build_gitingest.py --only karl_zylinski

# check what would change (dry-run)
python _Helpers/scripts/scrapers/build_gitingest.py --check
```

The script reads the repo map in `_Helpers/config/gitIngest_repos.jsonc` and invokes `gitingest` for each entry.

### By hand (one-off)

```bash
gitingest "D:\Sources\Odin\karl_zylinski\github\metroidvaniaish" \
    -o "odin-knowledge-base/gitIngest/karl_zylinski/metroidvaniaish.txt"
```

Useful gitingest flags:

- `-s 100000` skip files > 100 KB (default in the script: 200 KB)
- `-e "build/**" -e "*.exe" -e "*.dll"` exclude build artefacts
- `-b main` pin a branch (not used here, local clones)

## Conventions

- One `*.txt` per repo, named after the repo folder.
- Files are added to `.gitignore` if they contain non-redistributable content. The whole `gitIngest/` folder is currently **not** gitignored (these are just local snapshots of public repos), but a per-folder `.gitignore` can be added if any private fork is ever included.
- Each snapshot is regenerated **on demand** - no scheduled job. The script logs generation date into a sidecar `*.json` (`source`, `generated_at`, `size_bytes`, `gitingest_version`).
- Snapshots larger than ~5 MB are still kept (gitingest handles them), but you may want to use `-s` to trim.

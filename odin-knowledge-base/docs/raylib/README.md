## How this folder was populated

`odin-knowledge-base/docs/raylib/changelog/*.md` is produced by `_Helpers/scripts/scrappers/scrape_raylib_changelog.py` (GitHub Releases API). Re-running is idempotent - already-scraped releases (matched by frontmatter `tag:`) are skipped unless you pass `--force`.

```bash
python _Helpers/scripts/scrappers/scrape_raylib_changelog.py            # last 10 releases
python _Helpers/scripts/scrappers/scrape_raylib_changelog.py --limit 30 # last 30
python _Helpers/scripts/scrappers/scrape_raylib_changelog.py --force    # force re-write
python _Helpers/scripts/scrappers/scrape_raylib_changelog.py --check    # dry-run
```

The scraper accepts the optional env var `GITHUB_TOKEN` to raise the GitHub API rate limit from 60 to 5000 requests/hour.

## Files produced

| File                            | Format                                      | Purpose                                           |
| ------------------------------- | ------------------------------------------- | ------------------------------------------------- |
| `changelog/raylib_changelog.md` | Consolidated file (one section per release) | All releases in one file for LLM context (126 KB) |

The 10 most recent Raylib releases are tracked (3.0.0 → 6.0 / 4.6-dev as of 2026-07-04). Add `--limit 30` to extend the window.

## Note on Odin bindings

This folder tracks the **C library** only. The Odin binding (`vendor:raylib`) is shipped with the Odin compiler and tracked separately under `odin-knowledge-base/docs/official/vendor/raylib/`. A future `scrape_raylib_odin_bindings.py` (deferred sine die, see `_Private/raw/Perplexity backlog/2026-07-04_04_odin_assistant_optimisation_espace_perplexity.md` § 4.2) could cover third-party bindings like `Aronicu/raylib-odin` if needed.
